# Kapanış ve Soru-Cevap

**Süre:** 5 dk · **Çıktı:** Sonraki adımlar

## Bugün ne inşa ettik?

| Modül | Ne öğrendik | Ne ürettik |
|---|---|---|
| M1 | Token, context, yapılandırılmış çıktı | `Karar` şeması |
| M2 | Embedding, vektör DB, RAG | Kaynak gösteren politika asistanı |
| M3 | Bilgi grafı, kişiselleştirilmiş PageRank | Role göre sıralanan sonuçlar |
| M4 | LangChain araçları, LangGraph durum makinesi | Hafızalı, araç kullanan ajan |
| M5 | Supervisor, multi-agent, MCP | 3 ajanlı karar ekibi + MCP sunucusu |
| M6 | .NET SSE streaming, React | Uçtan uca sohbet ve karar ekranı |
| M7 | Eval, güvenlik, maliyet | Üretim kontrol listesi |

## Sonraki adımlar

1. **Bu hafta:** Kendi ekibinizden 1 karar sürecini seçin (onay, sınıflandırma, triage). 20 örnek toplayın.
2. **2 hafta:** M1 + M2 ile prototip. Altın soru setiyle ölçün.
3. **1 ay:** Gerekirse ajan/araç ekleyin (M4). .NET arayüzü ile pilot kullanıcılara açın (M6).
4. **Sürekli:** M7 kontrol listesini proje kapısı (gate) olarak kullanın.
